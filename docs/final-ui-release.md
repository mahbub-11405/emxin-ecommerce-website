# EMXIN Final UI Release

The customer storefront and admin visual system are aligned to the approved EMXIN reference: white background, compact typography, blue accents, clean cards, minimal clutter and strong product-first hierarchy.

Locked business rules include dynamic CMS content, stock visibility, stock-out state, quantity requests, optional dealer registration, 20+ bulk pricing, 50% bulk advance, retail COD/PayStation, fixed 2% retail digital-payment discount, coupons, manual admin courier confirmation, Steadfast/Pathao adapters, CRM/analytics, bilingual-ready content and S3/CloudFront media.
